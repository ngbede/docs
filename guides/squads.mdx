## Overview
Squads represent each user's team selection. Use these endpoints to create squads, view them, and fetch lineup details.

## Key endpoints
- [Create squad](/api-reference/squad/create)
- [List squads](/api-reference/squad/list)
- [Get squad](/api-reference/squad/get-by-id)
- [Get squad lineup](/api-reference/squad/get-lineup)
